# Fictional examples

Jordan Rivera and the employers, work history, qualifications, job and outcomes here are invented for testing. They are not anonymized records from a real candidate. Reserved `example.com` addresses are placeholders; do not contact them or attempt an application.

- [Candidate CV data](candidate/cv.json) demonstrates a short evidence-based CV.
- [Profile review](candidate/profile-review.md) shows how to turn gaps into a conversation.
- [Claim ledger](candidate/claims.json) distinguishes supported, disputed and unknown claims.
- [Application form notes](application/job.md), [answers](application/answers.md) and [review](application/review.md) show a complete draft review, including a decision still needed.
- [Practice form](practice/index.html) runs locally and simulates four outcomes without sending data.

To try the browser fixture, run `python3 scripts/nox.py practice` and open the printed localhost address. Use only the included [dummy upload](practice/dummy-cv.txt). Stop the server with Ctrl+C.

To generate the CV, follow [the document guide](../docs/documents.md). Generated review files are kept in ignored `.runtime/`; personal information must never be put into these examples. The example application is **not approved**. Example evidence dates describe the invented scenario, not actual user confirmations.
