# Standard answers

Almost every application form asks these questions. Answer them once during setup and bulk applying becomes possible. The assistant reuses these answers and asks only when something new comes up.

How this file works:

- Write the answer after the colon. Add `(confirmed YYYY-MM-DD)` once the person has confirmed it.
- Blank means unknown: ask, never guess. "Ask me each time" is a valid answer.
- "Suggested:" is a starting point the person hasn't chosen yet. Replace it with their choice.
- Read the actual question before reusing an answer. "Do you have the right to work?" and "Will you need sponsorship?" usually need opposite yes/no answers.
- Answers depend on the country. Record them separately for each target country.
- A required question needs a response, not necessarily a value. "Prefer not to say", "Negotiable" or "N/A" is often a valid response.

## Policy questions

- How did you hear about us: Suggested: "Company website" (or "Online job search" if that's an option). Use the real source if it was a referral.
- Previously worked for this company: check the tracker and experience. Ask if unsure.
- Previously applied to this company: check the tracker. Ask if unsure.
- Relatives or friends who work there: Suggested: No. Confirm once.
- Equal-opportunities questions (gender, ethnicity, disability, veteran status, sexual orientation): Suggested: "Decline to self-identify" where offered. The person may choose to answer.
- Pronouns (optional):
- Criminal record: no default. The person answers this themselves or chooses "ask me each time".
- Marketing or future-opportunities emails: Suggested: decline.
- Required privacy or data-processing consent: Suggested: accept when it's needed to apply. Confirm once.
- Did you use AI to help with this application: answer truthfully. Suggested wording to confirm: "I used AI tools to help draft and format my application. The experience and achievements are my own."

## Other answers

Add new questions as they come up, so each one is asked only once. Use this format:

```md
### Short name of the question
- Meaning: what is being asked (and other wordings of the same question)
- Scope: which countries, companies or forms it applies to
- Answer: the exact wording
- Confirmed: YYYY-MM-DD, how (for example "in chat")
```

Company-specific answers (why this company, why this role) belong in each application's own `answers.md`, not here.
