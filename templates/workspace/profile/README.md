# Your profile

The assistant keeps these files up to date from your documents and conversations. You never need to edit them, but you can ask it to correct anything. A blank means unknown, not permission to guess.

| File | What it holds |
|---|---|
| facts.md | Name, contact details, location and links |
| answers.md | Standard form answers: right to work, salary, notice, policy questions, and every new answer you give |
| experience.md | Your full career history: roles, dates, responsibilities and results |
| claims.json | Key claims (titles, dates, numbers, qualifications), where each came from and whether you've confirmed it |
| stories.md | 8–12 specific examples for applications and interviews |
| preferences.md | What you're looking for: roles, locations, dealbreakers, companies, batch size |
| application-preferences.md | How applications are reviewed and approved |
| voice.md | How you write |
| open-questions.md | Gaps and conflicts still to resolve, and where setup left off |

Original documents go in `evidence/`, research in `research/`, and each job's materials in `applications/`. The tracker named in `workspace.json` holds every job's stage.

Recent, dated confirmations override older notes. A suggested answer isn't a confirmed one.
