# Send an idea or problem

Read and follow [the shared procedure](../../../workflows/feedback.md). Resolve personal paths from the workspace root containing `workspace.json`. If no workspace exists, guide setup first. Read the shared operating rules in `AGENTS.md`. Apply existing human authorization within its scope; skill selection itself grants no external-action authority.
